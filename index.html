04 · The origin

Liquid Time-Constant Networks (LTCs)

QuestionAnswer

WhereMIT CSAIL (Computer Science & AI Lab)

Core ideaEach neuron is a differential equation that evolves over time

05 · How it works

The time constant flows with the input

dx/dt = −[ 1/τ + f(x, I) ] · x + f(x, I) · A

x = neuron state · I = input · τ = time constant · f = learned function · A = bias

Normal continuous-time network

τ is fixed: every neuron reacts at one speed, whatever happens.

Liquid network

τ depends on the input: fast when inputs change, smooth when they're stable.

The liquid part!

06 · Reading the equation

Three forces inside every liquid neuron

−x / τ

1 · The leak

With no input, the neuron relaxes back to rest, like tea cooling down. τ sets how fast.

+ f · A

2 · The push

The input pulls the neuron towards a target value A. Stronger input, stronger push.

− f · x

3 · The speed-up

The same f also boosts the pull to (1/τ + f), so strong input means a faster reaction.

The key result

Effective τ = τ ÷ (1 + τ·f)

Resting point x* = f·A ÷ (1/τ + f) always lies between 0 and A, so the neuron can never blow up.

Calm input · f ≈ 0

τ stays 0.8 s: slow and smooth, ignores noise

Strong input · f = 10

τ drops to ≈ 0.09 s: about 9× faster

The liquid trick!

13 · The speed fix

From an ODE solver to a direct formula

LTC · 2020

Solve step by step

Each neuron is a differential equation, so a numerical ODE solver must crunch it in many small steps.

Result: slow to train and run

CfC · 2022

Closed-form Continuous-time

An approximate closed-form solution: one direct formula, no solver needed.

Result: much faster, same benefits

No solver needed!

15 · Uses & limits

Where liquid networks shine, and where they don't

Applications

  • Self-driving vehicles
  • Drones and robots
  • Medical monitoring
  • Financial forecasting
  • AI on small devices, no cloud

Limitations

  • Best on time-series data, less gain on static images
  • Not yet proven on the very largest models
  • Still an active research area
